# Contributing

## Development setup
- Backend: Python 3.10+ recommended. Use virtualenv and install `backend/requirements.txt`.
- Frontend: Any static server for `frontend/`. Later we will adopt Vite + React.

## Code style
- Python: follow PEP8, format with `black` (optional).
- Document public interfaces:
  - In Python routes, include docstrings and use `# PUBLIC_INTERFACE` markers for functions.

## Commit messages
Use concise, descriptive messages. Reference issues where appropriate.

## Opening PRs
- Include a brief description of changes and testing notes.
- Update documentation when interfaces or behaviors change.
